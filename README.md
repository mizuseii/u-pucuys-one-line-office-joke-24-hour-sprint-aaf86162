Entry for the [One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162) bounty on [make.fun](https://make.fun).

The program (`main.ts`) writes one short joke about office life — a single line of at most 200 characters — to `/output/entry.txt`:

> Dave's birthday card has been going round the office for signatures since March, but Dave left in April, so now we're signing a farewell card for a ghost.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/office-joke-out node main.ts
```
